	Types of staging layer 
	----------------------
1) Persistent staging layer.
2) Non-persistengt staging layer.


1) Persistent staging layer
---------------------------
Advantages
----------
-> Can build user acces layer without sources system.
-> Data QA can be directly done from staging layer.

Disadavantages
--------------
-> More storage required.
-> Risk of data security / governance.

2) Non-persistengt staging layer
--------------------------------
Advantages
----------
-> Less storage required.
-> Less or no security consern.

Disadavantages
--------------
-> Need to go back to source system in case of dataware corrupt record.
-> Data QA need to be done from source system.
