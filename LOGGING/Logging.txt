Logging Architecture
----------------------

1) Logger : This class providing method to generate log message

2) Layout : It represent log message structure (formate of log msg)

3) Appender : It is used to write log message to destination

4) Destiation : It can be console/file/database.

Note: We eill use files to store our log messages.

==============
Logging Levels
==============

1) TRACE
2) DEBUG
3) INFO (Default logging level in spring boot)
4) WARN 
5) ERROR 
6) FATAL

===================
Log level Hierarchy
===================

TRACE > DEBUG > INFO > WARN > ERROR > FATAL

=> When we set one Log level, application will print log messages from that 
   level to all higher level messages.
=> In Spring Boot by default it will use ConsoleAppender
