============
Git Branches
============

-> In project multiple development teams will be involved

	-> CR Team
	-> Enhancement team	
	-> R & D Team
	-> Prod team

-> When multiple teams are working parelelly code integration will be difficult.

-> Every team should have separate code base for easy maintenence

Note: Under one repository multiple branches will be created

=> using branches multiple teams can work paralelly.

=> we can create branches from git repository directly.

=> In every repository below branches will be available
	1) main / master
	2) develop
	3) feature-101
	4) research
	5) staging
	6) release

-> we clone git repo using 'git clone' commad (it will clone default branch) 

-> using git bash we can switch from one branch to another 
	
	$ git checkout <branch-name>

-> we can clon particular branch code also
 
 	$ git -b <branch-name> <repo-url>

-> we can check working tree pointing to which branch

	$ git branch

-> we can merge chenges from one branch to another branch using pull request.
